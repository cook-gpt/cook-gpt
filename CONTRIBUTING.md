# Contributing

Thanks for contributing to **cook-gpt**.

## Setup

```bash
git clone https://github.com/cook-gpt/cook-gpt.git
cd cook-gpt
```

Open `Cook GPT/Cook GPT.xcodeproj` in Xcode 16+ to build and run the iOS app.

## Pull requests

1. Branch from `main`.
2. Open a PR using the repository template.
